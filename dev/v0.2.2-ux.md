# GUI / UX 提案

対象は現行の4タブと整列ポップアップ。D07/D08 は承認後に追加する。この文書は単独で読める。

調査事実: ダーク（slate-950）固定。Framer Motion はダイアログのみ。Ctrl+Tab でタブ移動あり。除外は JSON 中心。整列は 1〜4 キー。トレイ常駐。設定を閉じると WebView 破棄。

## 画面別

### 1. モニター構成（map）

**ワイヤーフレーム（テキスト）**

```
+------------------+--------------------------------------+
| サイドバー        | モニターマップ                       |
|  マップ          |  [SVG 物理配置]                      |
|  除外            |                                      |
|  設定            |  選択時: グループ / 順位 / プライマリ |
|  について        |                                      |
+------------------+--------------------------------------+
```

**コンポーネント**: `Sidebar`, `MonitorMap`, 選択時オーバーレイ（既存）

**操作フロー**: クリック選択 → 欄外クリック解除（v0.2.1）。グループ色はクリックサイクル。

**0.2.2**: 見た目変更なし。D04 で抜いたモニタが消えるのは OS 座標の反映。

**D08 承認時**: 下部に折りたたみ「配置の詳細」。初心者は閉じたまま。

### 2. 除外リスト

**ワイヤーフレーム**

```
[ウィンドウ選択 ▼] [リロード] [ルールに追加]
ピン留め提案バナー（あるときだけ）
[ JSON エディタ  全幅 ]
フルスクリーン / 最小化 トグル（設定タブと同期するなら片方に寄せる）
```

トグルが設定タブと除外タブで二重なのは学習コスト。0.2.2 では動作を変えない。中期で「状態フィルタは除外タブのみ、設定タブはリンク」にする。

**コンポーネント**: `ExclusionPanel`, 将来 `RuleBuilder`（視覚エディタ）

**キーボード**: JSON 内はブラウザ既定。Ctrl+Tab がタブ移動と衝突する。**既知の問題。** 除外タブで Ctrl+Tab を「インデント」に取られる。`App.tsx` は `e.preventDefault` しているため JSON 内でもタブが切り替わる。

0.2.2 修正: `activeTab === "exclusion"` かつ target が textarea のときは Ctrl+Tab をアプリで使わない。
