# D02 CLI 契約とアクション単一ディスパッチ

状態: 短期 **0.2.2**。

## 背景

入口が3つある。

1. グローバルホットキー（`hotkey.rs`）
2. CLI / 第二インスタンス（`lib.rs::dispatch_cli_action`）
3. 設定画面からの `trigger_action`（rotate / undo / swap のみ）

README は `--shift-next` と `--swap 1 2`。SPEC v0.2 と実装は `--rotate-cw` と `--swap=N`。利用者が Stream Deck に README を写すと動かない。

## 目的

実行する処理を1つの enum で表す。上記の3経路では、共通の処理を呼ぶだけにする。CLI の引数表記は文書と実装で揃える。

## 機能概要

- `Action` enum を新設する。
- `dispatch_action(app, action)` が pin / escape / gather / arrange / rotate / undo / swap を全部扱う。
- CLI は **実装を正** とし、README を合わせる。互換エイリアスとして `--shift-next` = `--rotate-cw`、`--shift-prev` = `--rotate-ccw` を残す。
- `--swap 1 2` は「モニタ1と2を交換」だが現行ロジックは「プライマリと番号 N」。仕様を変えない。README の例を `--swap=2` に直す。誤って `--swap 1 2` が来たらエラーメッセージを出して終了する。
- `trigger_action` の文字列を enum にマップし、不足アクションを足す。

## ユースケース

- UC-1 Stream Deck が `ChuwitchWindow --rotate-cw` を送る。常駐中なら即実行して起動プロセスは終了。
- UC-2 未常駐で `--undo` → ワンショット実行して終了（現状どおり）。
- UC-3 README の古い `--shift-next` でも動く。
- UC-4 設定画面のテストボタン（将来）が `trigger_action("escape")` を呼ぶ。

## 画面遷移

なし。About タブの CLI 説明文を更新するだけ。

## 処理フロー

```
argv / IPC args / trigger_action string
    → parse_action(args) -> Result<Vec<Action>, ParseError>
    → 各 Action について dispatch_action(app, action)
    → 1件でも実行したら CLI ワンショットなら exit(0)

parse_action:
  --rotate-cw | --shift-next → Rotate { clockwise: true }
  --rotate-ccw | --shift-prev → Rotate { clockwise: false }
  --undo → Undo
  --pin-toggle → PinToggle
  --escape → Escape
  --gather → Gather
  --arrange → Arrange
  --swap=N → Swap { target: N }  (N は 2..=9。1 はプライマリ自身なので拒否)
  --swap <a> <b> → Error("use --swap=N where N is the target monitor number")
```

未知の `--` で始まる引数はエラー。`--autostart` / `--hide` / `-hide` はアクションではない（常駐起動フラグ）。

## API 設計

### `parse_cli_actions(args: &[String]) -> Result<Vec<Action>, ParseError>`

- 引数: `std::env::args()` 相当。index 0 の exe 名は無視。
- 戻り値: アクションのリスト。フラグのみなら Ok(empty)。
- 入力例: `["ChuwitchWindow.exe", "--rotate-cw"]`
- 出力例: `Ok(vec![Action::Rotate { clockwise: true }])`

### `dispatch_action(app: &AppHandle, action: Action)`

- pin は `pin::toggle_pin` + `emit("pin-toggled")`
- arrange は `show_arrange_window`
- その他は既存 `logic::*`

### Tauri `trigger_action(action: String)`

許可する文字列（これ以外は `Err`）:

`rotate_cw` `rotate_ccw` `undo` `pin_toggle` `escape` `gather` `arrange` `swap_target_2` … `swap_target_9`

現状は `Result` を返していない。`Result<(), String>` に変更する。フロントに trigger 呼び出しが無ければコンパイルだけ確認。

## エラーハンドリング

| 入力 | 結果 |
| --- | --- |
| `--swap=1` | エラー「target must be 2-9」終了コード 1 |
| `--swap=abc` | エラー |
| `--swap 1 2` | エラー（使い方を stderr へ） |
| 未知オプション | エラー |
| アクションなし + GUI 起動 | 現状どおり常駐 |

ワンショットでアクション実行後は現状どおり `exit(0)`。パース失敗は `exit(1)`。常駐中の第二インスタンスはパース失敗をログに出し、自分は終了（メインは殺さない）。

## テスト方針

`action.rs` に単体テスト。Win32 は呼ばない。

正常: 各フラグ、エイリアス、複数フラグ（`--rotate-cw --undo` は両方返す。実行順は引数順）。

異常: `--swap 1 2`、空の `--swap=`、`--swap=0`、`--swap=10`。

境界: `--swap=2` と `--swap=9` は Ok。

### サンプル: parse

```rust
pub fn parse_cli_actions(args: &[String]) -> Result<Vec<Action>, ParseError> {
    let mut actions = Vec::new();
    let mut i = 1; // skip argv0
    while i < args.len() {
        let a = args[i].as_str();
        match a {
            "--autostart" | "--hide" | "-hide" => {}
            "--rotate-cw" | "--shift-next" => actions.push(Action::Rotate { clockwise: true }),
            "--rotate-ccw" | "--shift-prev" => actions.push(Action::Rotate { clockwise: false }),
            "--undo" => actions.push(Action::Undo),
            "--pin-toggle" => actions.push(Action::PinToggle),
            "--escape" => actions.push(Action::Escape),
            "--gather" => actions.push(Action::Gather),
            "--arrange" => actions.push(Action::Arrange),
            "--swap" => {
                return Err(ParseError {
                    message: "use --swap=N (N = 2..9, primary vs that monitor)".into(),
                });
            }
            other if other.starts_with("--swap=") => {
                let n: u32 = other[7..].parse().map_err(|_| ParseError {
                    message: "invalid --swap=".into(),
                })?;
                if !(2..=9).contains(&n) {
                    return Err(ParseError { message: "swap target must be 2..9".into() });
                }
                actions.push(Action::Swap { target: n });
            }
            other if other.starts_with('-') => {
                return Err(ParseError { message: format!("unknown option: {other}") });
            }
            _ => {}
        }
        i += 1;
    }
    Ok(actions)
}
```

fn shift_next_alias() {
