# D09 完全オフライン化（更新確認の削除）

状態: 短期 **0.2.2**。決定 Q5-B。

D06（CSP / `open_url` 制限）とは別件。Q12 により D06 は実施しない。

## 背景

`AboutTab.tsx` がマウント時に `https://api.github.com/repos/KotorinChunChun/ChuwitchWindow/releases/latest` を `fetch` し、新しいタグがあれば「アップデートあり」を出す。Q5-B により、アプリは自動でネットワークを使わない。

## 目的

設定画面を開いただけでは外部へ接続しない。更新の有無はユーザーがブラウザで Releases を見る。

## 機能概要

1. GitHub API の `fetch` と `updateAvailable` 状態を削除する。
2. 「アップデートあり」表示を削除する。
3. 「更新履歴」や GitHub へのリンクボタンは残す（クリック時のみ `open_url`。Q5 の解釈どおり）。
4. フロントから他の `fetch` / WebSocket を足さない。

## ユースケース

- UC-1 オフライン PC で About を開く。待ちもエラーも出さず、バージョン文字列だけ見える。
- UC-2 ユーザーが GitHub リンクを押す。ブラウザが開く（従来どおり）。

## 画面遷移

About タブ: バージョンの横に更新バッジが出ない。ほかのタブは変更なし。

## 処理フロー

```
About マウント
  getVersion() → 表示
  fetch しない
  ログ取得は従来どおり（ローカルファイル）
```

## データ構造

変更なし。ネットワーク用の設定項目は作らない。

## API 設計

Tauri コマンド追加なし。削除するのはフロントの `fetch` のみ。

`getVersion` は `@tauri-apps/api/app` のローカル API。ネットワークではない。残す。

## エラーハンドリング

更新確認失敗の `catch` ごと消える。リンクの `open_url` 失敗は既存ダイアログ。
