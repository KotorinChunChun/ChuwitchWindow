## 背景

- `tauri.conf.json` の `csp` が `null`。設定 WebView はローカルだが、About タブが GitHub API を `fetch` する。
- `open_url` は任意文字列を `cmd.exe /C start {url}` に渡す。`&` や `"^` でコマンド連結できる。
- capabilities は `allow-all` と死んだ `greet`。`osd` ウィンドウが残っている。
- 管理者再起動は製品上必要。既定を管理者にはしない。
- コード署名は無し（Q12 / 長期）。

## 目的

設定 UI からできることを、本アプリに必要な範囲へ閉じる。外部通信は GitHub の更新確認のみと文書化する。

## 機能概要

1. CSP を設定する（既定の Tauri ローカル + GitHub API / アバターが要るなら最小）。
2. `open_url` を https の許可ホストだけに制限する。
3. `ShellExecuteW` または `open::that` 相当で URL を開き、`cmd /C start` をやめる。
4. capabilities から `osd` と `greet` を削除し、コマンドを列挙のまま（allow-all 識別子は残して中身を実コマンドだけに）。
5. `js_debug_log` は debug ビルドのみ、または削除。本番でフロントから任意ログを吹けるのは不要。

## ユースケース

- UC-1 ユーザーが GitHub リンクをクリック → ブラウザがリポジトリを開く。
- UC-2 改ざんされたフロントが `open_url("https://evil")` → 拒否。
- UC-3 `open_url("https://github.com/foo & calc.exe")` → 拒否（URL パース失敗または非許可）。

## 画面遷移

About のリンクが失敗したら既存ダイアログでエラー。

## 処理フロー

```
open_url(url: String)
  parsed = Url::parse
  if scheme != https: Err
  if host not in allowlist: Err
  ShellExecuteW(NULL, "open", wide(url), ...)
```

許可ホスト（旧稿。0.2.2 では本設計を実施しない）:

- `github.com`
- `api.github.com`（fetch はフロント。open は不要だが誤って渡してもよい）
- `avatars.githubusercontent.com`（開く必要は無い。許可しなくてよい）

About の fetch は `https://api.github.com/repos/KotorinChunChun/ChuwitchWindow/releases/latest` のみ。CSP `connect-src` にこれを含める。

## API 設計

`open_url` の戻り値を `Result<(), String>` に変更。

CSP 例（Tauri 2 の ipc を壊さないこと。公式テンプレをベースに `connect-src` だけ足す）:

```json
"csp": "default-src 'self'; connect-src 'self' https://api.github.com ipc: http://ipc.localhost; img-src 'self' https://avatars.githubusercontent.com data:; style-src 'self' 'unsafe-inline'"
```

`'unsafe-inline'` は Tailwind 実行時には不要（ビルド済み CSS）。既存がインライン style を使うなら残す。`CustomDialog` 等を確認し、不要なら外す。

## エラーハンドリング

拒否時: `"URL is not allowed"` を返し、ログに host を出す。コマンドは実行しない。

## テスト方針

`is_allowed_url(url: &str) -> bool` を純粋関数としてテスト。

| ID | 入力 | 期待 |
| --- | --- | --- |
| SEC-01 | `https://github.com/KotorinChunChun/ChuwitchWindow` | true |
| SEC-02 | `http://github.com/` | false |
| SEC-03 | `https://evil.com` | false |
| SEC-04 | `https://github.com.evil.com` | false（host 完全一致） |
| SEC-05 | `https://github.com/foo"&calc` | false |
| SEC-06 | 空文字 | false |

パフォーマンス非該当。境界: 末尾スラッシュ、大文字 HOST は Url クレートの正規化後で比較（lowercase）。

依存: `url` crate を `src-tauri/Cargo.toml` に追加してよい。

### サンプル

```rust
pub fn is_allowed_url(input: &str) -> bool {
    let Ok(u) = url::Url::parse(input) else { return false };
    if u.scheme() != "https" { return false; }
    let Some(host) = u.host_str() else { return false };
    matches!(host, "github.com" | "www.github.com")
}
```

`ShellExecuteW` の使い方は既存 `admin.rs` のパターンをコピーする。`cmd` を新たに足すな。
