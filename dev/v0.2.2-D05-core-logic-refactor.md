# D05 コア移動ロジックの共通化

状態: 短期 **0.2.2**。D02 の後が望ましい。

## 背景

`logic.rs` の `handle_rotate` / `handle_swap_target` / `handle_escape` / `handle_gather` が、設定読込・ルールパース・ピンフィルタ・履歴 push・`group_windows_by_monitor` をコピーしている。除外条件を1つ足すと4箇所必要。小型モデルが1箇所だけ直す事故が起きやすい。

`hotkey.rs` も同じアクションをネストした if で呼ぶ。

## 目的

移動対象と移動先を求める計算を、Win32 で移動を実行する処理から分ける。フィルタと履歴処理は1つの関数にまとめる。ホットキーは D02 の `Action` を呼ぶ。

本設計は挙動を変えないリファクタである。スワップのソート順（`left` 座標）やグループシフトの意味を変えてはならない。

## 機能概要

```rust
pub struct MoveContext {
    pub monitors: Vec<MonitorInfo>,
    pub windows_by_monitor: Vec<Vec<WindowInfo>>,
}

pub fn collect_movable(app_not_needed: ()) -> (AppConfig, Vec<MonitorInfo>, Vec<WindowInfo>) {
    // load config, parse rules, get monitors, get windows, filter pin+rules

pub fn push_history(app: &AppHandle, windows: &[WindowInfo]); // D03 後は placement 付き

pub fn handle_action(app: &AppHandle, action: Action);
```

rotate のグループ分岐は `handle_rotate` 内に残してよい。共通化するのは収集と履歴だけでも価値がある。やりすぎた「巨大 Strategy トレイト」は作らない。

## ユースケース

開発者・AI が除外条件を1行足して全アクションに効かせる。

## 画面遷移

なし。

## 処理フロー

```
Action
  → collect_movable()
  → match action { Rotate, Swap, Escape, Gather, Undo, Pin, Arrange }
  → 各専用関数は MovableSet を受け取る（Undo/Pin/Arrange は例外）
```

Pin は窓一覧不要。Arrange は `arrange.rs` のまま。Undo は history のみ。

## API 設計

フロント API 変更なし。`handle_action` は D02 の `dispatch_action` の中身になる。

ホットキースレッド:

```rust
if let Some(action) = action_from_hotkey_event(&config, event.id) {
    crate::action::dispatch_action(app_handle, action);
}
```

`action_from_hotkey_event` は id 比較をテーブル化:

```rust
struct HotkeyBinding { hotkey: HotKey, action: Action }
```

reload 時に Vec を作り、受信時は id で find。ネスト if を削除。

## エラーハンドリング

現状どおり空なら return。unwrap を新たに増やさない。Mutex 毒は既存方針。

## テスト方針

`collect` のフィルタを単体で試すには `WindowInfo` フィクスチャで `filter_movable(windows, rules, pinned)` を切り出す。

```rust
pub fn filter_movable(
    windows: Vec<WindowInfo>,
    rules: &RuleNode,
    is_pinned: impl Fn(isize) -> bool,
) -> Vec<WindowInfo>
```

入力例: 3窓、1つ pin、1つ最小化ルール一致、1つ普通。  
出力例: 1要素。

ホットキーテーブル: 文字列 `Win+Ctrl+Alt+E` → Escape を parse して id 一致をテスト（GlobalHotKey がプロセス内で register せず `parse_hotkey` の純粋部分だけ）。

`parse_hotkey` を `pub(crate)` にしてテスト。今は private。
