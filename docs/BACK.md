## 開発の背景

作者は日頃から3台～6台のモニターを使っています。最も見やすい正面のメインモニターには注視するアプリのウィンドウを置き、サブモニターには補助的な情報を表示するウィンドウを置きます。

普段はサブモニタに置いているアプリでも、メインモニターに移したくなることがあります。メインモニターにあるアプリの手前に移すと、せっかく重ならないように並べたウィンドウが重なり、サブモニタには空きができてしまいます。

モニタに表示するウィンドウが1つだけの場合もありますが、2つ～4つのアプリを同時に見られるように並べることもよくあります。そこで、モニタに表示しているウィンドウをすべてまとめて入れ替えたいと、以前から考えていました。

解決策を以前から探していましたが、試した機能やツールでは、期待した動作を得られませんでした。

## 類似ツール

Windowsには、アクティブなウィンドウを他のモニタへ移動するショートカットキー `Win + Shift + 左右矢印` があります。ただし、複数のウィンドウを同時に移動したり、移動先のウィンドウと入れ替えたりする手段はありません。

Windowsの仮想デスクトップ機能 `Win + Ctrl + D` と `Win + Ctrl + 左右矢印` を使うと、少ないモニタで多くのアプリを切り替えて表示できます。少ないモニタを使い回すための機能なので、マルチモニタ環境を効率化するという目的とは方向が逆です。

PowerToys の FancyZones「ウィンドウ管理」機能は、ウィンドウの移動操作を極限まで効率化してくれますが、「そもそも移動しなくてもいい」という水準の機能は提供していません。

アプリのウィンドウの配置を記憶して自動的に配置する機能を備えたアプリは多数ありますが、これらはモニタの決まった位置にウィンドウを配置することはできても、異なるモニタに配置する機能は提供していません。
