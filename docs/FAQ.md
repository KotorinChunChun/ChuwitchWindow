# よくある質問

基本操作は [README.md](../README.md) にあります。開発の背景とショートカットキーの一覧は [USERS_GUIDE.md](USERS_GUIDE.md) にあります。

## 管理者権限のアプリが動かない

通常は一般ユーザー権限で動作します。その場合、管理者として実行されているウィンドウは移動できません。設定画面の **「管理者として再起動する」** を使ってください。スタートアップの登録・解除にも管理者権限が必要です。

## 設定ファイルはどこか

`%APPDATA%\kotorichun\chuwitchwindow\config.json` です（`com.kotorichun\...` ではありません）。

## CLI で巡回シフトや入れ替えを実行するには

公開版 v0.2.1 と開発版 v0.2.2 では、`--rotate-cw` で次のモニターへ、`--rotate-ccw` で前のモニターへ巡回シフトします。プライマリモニターと指定したモニターのウィンドウを入れ替えるには、`--swap=N` の `N` に対象のモニター番号を指定します。モニター2を指定する場合は `--swap=2` です。

開発版 v0.2.2 では `--shift-next` と `--shift-prev` も使えます。`--swap 1 2` 形式はどちらのバージョンでも使えません。

## アプリを終了したつもりがトレイに残っている

設定画面を閉じる（×）か最小化すると、アプリはタスクトレイに格納されます。アプリを終了するには、トレイアイコンを右クリックして「終了」を選びます。

## 更新の自動確認はするか

しません（決定 Q5-B）。GitHub の Releases をブラウザで見てください。設定画面の GitHub リンクから開けます。
